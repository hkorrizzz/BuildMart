**BuildMart — Интернет-магазин строительных материалов (2026)**  

**Стек технологий**  
- Frontend: React 18, React Router v6, CSS Modules
- UI-библиотека: Material UI (Slider, Checkbox)
- Иконки: React Icons (Lu, Fa, Ri)
- Хранение данных: LocalStorage (корзина, избранное)
- Сборка: create-vite@latest 
- Язык: JavaScript
- Хранение данных: LocalStorage (корзина), JSON (каталог)
- Хостинг: GitHub Pages (**https://hkorrizzz.github.io/BuildMart/**)

**Основной функционал**  
- Каталог товаров с карточками
- Фильтрация по рейтингу (3+, 4+, 5+ звёзд)
- Фильтрация по ценовому диапазону
- Сортировка по имени (А-Я), цене (возрастание/убывание)
- Карточка товара с галереей изображений, описанием и характеристиками
- Похожие товары (related products)
- Корзина (добавление/удаление, изменение количества)
- Подсчёт суммы, налога и итоговой цены
- Промокод SAVE10 (скидка 10%)
- Toast-уведомления при добавлении в корзину
- Адаптивный дизайн
